STRING FUNCTIONS IN C

QUESTION 1

Write a C program to find the length of a string using strlen() function.

Program:

#include < stdio.h >
#include < string.h >

main()
{
    char Str1[20] = "Micro Solution";

    printf("length of Str1 : %d", strlen(Str1));
}

Output:

length of Str1 : 14

QUESTION 2

Write a C program to compare two strings using strcmp() function.

Program:

#include < stdio.h >
#include < string.h >


main()
{
    char s1[20] = "Micro Solution";
    char s2[20] = "Abishek";

    if(strcmp(s1,s2)==0)
    {
        printf("String 1 and String 2 are equal");
    }
    else
    {
        printf("String 1 and 2 are different");
    }
}

Output:

String 1 and 2 are different

QUESTION 3

Write a C program to join two strings using strcat() function.

Program:

#include < stdio.h >
#include < string.h >


main()
{
    char s1[20] = "Welcome to";
    char s2[20] = " Micro Solution";

    strcat(s1,s2);

    printf("Output string after concatenation: %s",s1);
}

Output:

Output string after concatenation: Welcome to Micro Solution

QUESTION 4

Write a C program to copy one string into another using strcpy() function.

Program:

#include < stdio.h >
#include < string.h >

main()
{
    char s1[30] = "Learn C Programming";
    char s2[30];

    strcpy(s2,s1);

    printf("String s2 is : %s",s2);
}

Output:

String s2 is : Learn C Programming

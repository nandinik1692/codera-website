 Pointers in C Language

Question 1: Write a C program to display the value and address of a variable using a pointer.
Program:
 #include < stdio.h >

int main()
{
    int a = 50;
    int *p;

    p = &a;

    printf("Value is %d", a);
    printf("\nAddress is %p", (void *)&a);
    printf("\nValue using pointer is %d", *p);

    return 0;
}

output:
Value is 50
Address is 0x7ffe1234
Value using pointer is 50
